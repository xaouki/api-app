# Gig Factory

A free, browser-only helper for preparing Fiverr gig drafts.

## Features
- Generate 1–20 gig drafts by category
- Titles, descriptions, keywords, packages, delivery and revisions
- Copy individual gig drafts
- Export all drafts to JSON
- No backend, database or paid API required
- Designed for manual publishing on Fiverr

## GitHub Pages
Enable Pages for the `main` branch and `/ (root)` in the repository settings.

## Important
This tool prepares content only. It does not automate login, clicking, messaging or publishing on Fiverr.
